# Caritas website (React + Vite)

    npm install
    npm run dev      # open the address shown in the terminal
    npm run build    # production files go to /dist

Edit your real text, phone, email, address, services, projects and photos in `src/data/content.js`.
To use real photos: put them in `public/photos/` and set `img: "/photos/name.jpg"` in the gallery list.
